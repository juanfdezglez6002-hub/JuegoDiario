# LEGENDARIO

El reto diario de videojuegos en el que gana la respuesta más rara.

Cada día salen 5 preguntas de juegos distintos (Minecraft, Pokémon, GTA V, Rocket League, Among Us, Mario Kart 8 Deluxe, EA Sports FC y Zelda: Breath of the Wild). Tienes 30 segundos para cada una. Cualquier respuesta válida suma, pero cuanto más rara sea, más puntos consigues:

| Rareza | Puntos |
|---|---|
| ⬜ Común | 10 |
| 🟦 Raro | 25 |
| 🟪 Épico | 50 |
| 🟨 Legendario | 100 |

## Características

- Reto diario igual para todos los jugadores, que cambia a las 00:00 (hora peninsular española)
- Rotación justa de juegos y preguntas
- Autocompletado al escribir
- Modo práctica libre y práctica por juego
- Guía «Descubre los juegos» para quien no conoce alguno
- Racha y estadísticas guardadas en el navegador (sin cuentas ni datos personales)
- Resultado para compartir con emojis

## Estructura

Todo está en un único archivo, `index.html`, con el HTML, el CSS y el JavaScript dentro.

El banco de juegos y preguntas está en el propio archivo, entre las marcas `/* ===BANCO-INICIO=== */` y `/* ===BANCO-FIN=== */`.

---

Proyecto independiente de fans, sin relación oficial con ninguno de los juegos mencionados. Todas las marcas pertenecen a sus respectivos propietarios.
